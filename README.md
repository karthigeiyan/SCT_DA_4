Task 4 - Business Insights Report (EDA)

Objective
Perform Exploratory Data Analysis (EDA) on a marketing campaign dataset and generate business insights.

Tools Used
* Python
* Pandas
* Matplotlib
* VS Code

Dataset
Marketing Campaign Dataset

Analysis Performed
* Data Cleaning
* Missing Value Handling
* Customer Age Analysis
* Income Analysis
* Campaign Response Analysis
* Product Spending Analysis

Key Insights
* Average Income: 52,247
* Average Spending: 607
* Campaign Response Rate: 15%
* Wine products generated the highest spending.
* Higher-income customers spent more.

Recommendation
Increase investment in web and catalogue marketing channels while optimizing low-performing campaigns.
